# Contributing

Thanks for helping improve this protocol. Keep changes understandable for people unfamiliar with programming or formal project management.

## Before proposing a change

- Describe the expected behavior and the observed problem.
- Separate a **protocol rule** from a **ChatGPT interface limitation**.
- Do not impose the full workflow on small tasks: simplicity is a quality requirement.
- Keep `HUMAN VERIFICATION: REQUIRED / NOT REQUIRED` at the end of **every phase**.
- Never claim the buttons are universally supported.
- Ensure that Continue, Copy, and the preview use exactly the same prompt where supported.

## Suggesting changes

Open an issue to explain the need, or propose changes to Markdown files. Include affected files and a before/after request example. Significant changes should explain their impact on `RULES.md`, `WORKFLOW.md`, `CONTINUATION_UI.md`, and `START_PROMPT.md`.

## Reporting bugs

Provide the user's objective, prompt, observed behavior, expected result, model/client when known, and whether the entire protocol was accessible. Remove private information before posting publicly.
