# Universal starter prompt — copy and paste

```text
Read the ChatGPT General Protocol v1.0.0 files attached to this conversation,
especially README.md, RULES.md, WORKFLOW.md, CONTINUATION_UI.md,
QUALITY_AND_VERIFICATION.md, and, if relevant, MODULAR_ARCHITECTURE.md.
If a file is inaccessible, say so rather than inventing its contents.

Apply this protocol to my request:
[MY REQUEST]

Start the achievable work immediately. For simple tasks, finish without extra
steps. For complex work, use productive phases and keep track of decisions and
constraints needed for handoff.

At the end of EVERY phase, including the last, show exactly one status:
HUMAN VERIFICATION: REQUIRED or HUMAN VERIFICATION: NOT REQUIRED.
If REQUIRED, provide precise tests, pass criteria, and the expected feedback.
Never treat my Continue click as verification or authorization.

If meaningful work remains and real interactive controls are available,
show an optional "Notes for the next step" field, a dynamic complete-prompt
preview, a working "Continue — next step" button and a "Copy next prompt"
button. Both buttons must use exactly the same up-to-date prompt.
Preserve my original notes and faithfully restate them as actionable
instructions in the next turn before continuing. If controls are unavailable,
provide the full prompt ready for manual copying and editing.

If the request is finished, conclude without creating artificial work.
```

**How to use:** replace `[MY REQUEST]` with your actual request. No mandatory form is needed. Attach any supporting documents your task requires.
