# Contribuer

Merci de contribuer au protocole. Les changements doivent rester compréhensibles pour les personnes qui ne connaissent ni la programmation ni la gestion de projets.

## Avant de proposer un changement

- Décrivez le comportement attendu et le problème observé.
- Distinguez une **règle du protocole** d'une **limite de l'interface ChatGPT**.
- Évitez de rendre le protocole obligatoire pour les petites tâches : la simplicité est un critère de qualité.
- Conservez la règle `VÉRIFICATION HUMAINE : REQUIRED / NOT REQUIRED` à **chaque phase**.
- Ne présentez jamais les boutons comme universellement disponibles.
- Assurez-vous que **Continuer**, **Copier** et l'**aperçu** reposent sur le même prompt lorsque la plateforme les permet.

## Proposer une modification

Ouvrez une issue pour expliquer le besoin, ou proposez une modification des fichiers Markdown. Indiquez les fichiers touchés et un exemple de demande avant/après. Les modifications importantes devraient préciser leur impact sur `RULES.md`, `WORKFLOW.md`, `CONTINUATION_UI.md` et `PROMPT_DE_DEMARRAGE.md`.

## Signalement de bug

Indiquez : l'objectif utilisateur, le prompt utilisé, la réponse observée, le résultat attendu, le modèle/client si connu et si le protocole entier était accessible. Retirez les données privées avant publication.
